## About Me

I'm a mobile engineer with **6+ years of experience** shipping production apps for **Android and iOS**. My cross-platform work is done **exclusively with Kotlin Multiplatform (KMP)** — one shared Kotlin codebase for business logic, data, and networking, with fully native experiences on each platform.

- 📱 **Native Android** — Kotlin, Jetpack Compose, modern Android architecture
- 🍎 **Native iOS** — SwiftUI front-ends consuming shared KMP frameworks
- 🔀 **Kotlin Multiplatform** — shared modules powering both platforms from a single codebase
- 🔒 Much of my production KMP and iOS work lives in **private client/employer repositories** — happy to walk through architecture and case studies in an interview
